# 新增知识点

CSLearning 的知识图谱数据位于 `data/catalog.json`。页面从此文件读取知识点、知识域、讲解、易错点和练习；节点坐标由图谱布局自动计算，不需要手动指定。

## 使用脚手架

在项目根目录运行：

```powershell
node scripts/add-knowledge.mjs `
  --id cache-coherence `
  --title "缓存一致性" `
  --en "Cache Coherence" `
  --domain hardware `
  --book "计算机组成原理 · Cache" `
  --summary "多处理器如何协调缓存中的共享数据。" `
  --goal "能解释缓存一致性要解决的问题。" `
  --pre cache,memory-hierarchy `
  --ext cpu-pipeline
```

先加 `--dry-run` 可只检查参数和关系，不写入文件。

脚手架会：

1. 检查 ID、知识域、重复项和前置知识是否存在；
2. 拒绝造成必需前置关系循环的变更；
3. 将新节点追加到 `data/catalog.json`，标记为草稿；
4. 生成 `content/drafts/<id>.md`，包含讲义、例题、误区、练习和工具的写作模板。

重载网页后，新节点会按依赖深度和知识域自动排布。草稿节点先显示基础介绍和关系自测；完成讲义后，将 `lessonLibrary`、`lessonNotes`、`exerciseBank` 中对应的草稿内容替换成正式内容。

## 数据约定

- `pre`：必须先理解的知识点；形成有向无环图。
- `ext`：后续可学或相关联的知识点；不作为解锁条件。
- `group`：必须是 `groupMeta` 中已经定义的知识域。
- `entryPoint: true`：标记唯一学习起点；它必须没有前置知识，图谱会画特殊箭头指向它。
- 不要为了图形效果添加并不存在的依赖；可选关联应放在 `ext`。
- 内容要标出适用条件、例题推导和常见误区；历史信息需要可核验来源。

若要更换学习起点，使用 `--start`；起点不能有 `--pre`。脚手架会清除旧起点标记，并把旧入口接到新入口之后，以保持单一入口。

## 教材体例的正文块

`lessonLibrary.<id>.sections[]` 支持以下字段，页面会按教材排版渲染：

| 字段 | 渲染结果 |
|---|---|
| `body` | 正文段落 |
| `points` | 无序列表 |
| `formula` | 居中的公式条 |
| `def` | 定义框：`{ "label": "定义 1.1（偶数）", "text": "…" }` |
| `table` | 带表题的表格：`{ "caption": "表 1　记号约定", "head": ["记号","读法","含义"], "rows": [["…","…","…"]] }` |
| `proof` | 证明块：`{ "label": "定理 1.2　…", "text": "第一行\n第二行" }`，末行自动补 `□`；设 `"qed": false` 则不补 |
| `example` + `exampleLabel` | 编号例题 |

写作约定：首次出现的记号先在表格中给出读法与含义，再用于公式；定义、定理、例题使用编号，正文用陈述句，不使用第二人称口语。

## 实验与工具

内容分三层：

1. **教材实验**：按知识域注册在 `src/experiments/` 下的文件中，由 `src/experiments.js` 汇总；每个实验只服务一个知识点，1–3 步，有检查与解释。
2. **实验页**：由实验注册表自动生成，按知识点所属知识域分组，支持搜索；点击实验进入对应教材位置并定位到实验。
3. **工具**：注册在 `src/tools.js` 的 `TOOLS` 数组，按功能类目分组，是完整、可自由修改条件的沙盒，不要求完成步骤。

### 实验

| 字段 | 含义 |
|---|---|
| `id` | 实验唯一标识，用于教材内嵌与实验页链接 |
| `title` | 实验标题 |
| `nodeId` | 所属知识点 id，决定内嵌位置与实验页分组 |
| `domain` | 备用分组键；正常按 `nodeId` 所属知识域自动分组 |
| `summary` | 一句话说明实验要观察什么 |
| `steps` | 步骤数，显示在实验页卡片上 |
| `toolLinks` | 相关工具 id 数组，实验底部显示“打开某工具”入口 |
| `mount(root, context, experiment)` | 把实验挂载到 `root` 的函数；`context.openTool(toolId)` 可打开工具 |

教材默认只内嵌每个知识点的一个主实验：注册实验后自动插在“本节要点”“小结”或“总结”之前；若正文某节写了 `experiment` 字段，则以该字段中的**实验 id** 为准，在该节位置内嵌。知识点正文不再直接挂载完整工具。

实验完成状态保存在浏览器 `localStorage`，实验页可按“已完成 / 未完成”筛选；从实验打开工具再返回时，会保留当前实验的交互状态。进度按当前 origin 保存，`localhost`、`127.0.0.1` 与预览端口之间不共享。

实验文件按知识域拆分：`graph.js`、`numbers.js`、`repr.js`、`prog.js`、`hardware.js`、`os.js`、`network.js` 等。共用外壳和交互模板在 `src/experiments/shared.js`：

- `shell(experiment, body)`：实验标题、简介与工具入口；
- `mountChoiceSteps(...)`：逐步预测 / 判断，答对后揭示；
- `mountStepper(...)`：先逐步执行过程，最后回答一个问题；
- `table`、`visual`、`chips`、`choiceButtons`：常用小部件。

需要特殊图形或滑块时，可以直接用 `shell` 加自己的状态与事件绑定。所有实验只依赖 `root`，不要引用教材正文或全局 DOM。

### 工具

| 字段 | 含义 |
|---|---|
| `id` | 工具唯一标识，用于链接 |
| `title` | 工具页标题 |
| `group` | 所属知识域，用于默认归类与配色 |
| `category` | 工具页功能类目；未写时按 `TOOL_CATEGORY` 或 `group` 自动回退 |
| `summary` | 一句话说明，显示在工具卡片 |
| `nodes` | 可使用该工具的知识点 id 数组，仅用于说明，不再决定内嵌 |
| `formulas` | 可选，工具页公式区要展示的 LaTeX 字符串数组 |
| `mount(root, context)` | 把工具挂载到 `root` 的函数 |

工具页把标题和简介放在顶栏，卡片内直接以公式区开始，并按 `TOOL_CATEGORIES` 的固定顺序分组；工具页支持搜索。工具页会自动列出通过 `toolLinks` 引用它的实验，工具卡片显示相关实验数。公式均由 KaTeX 渲染。工具动态输出的文本也可以直接写 `$...$` 或 `$$...$$`；`mountTool` 会监听 DOM 变化并重新排版公式。

工具页使用固定高度工作台：公式默认折叠在工具底部，画布/结果在卡片内部滚动，页面本身不上下滚动。工具区域支持右键菜单：重置工具、复制当前结果、打开相关实验、返回知识点。`graph-studio` 使用画布 + 右侧分析栏的布局。

新增工具时：

1. 在 `src/tools.js` 写一个 `setupXxx(root)` 函数，只依赖传入的 `root`，不要依赖某个知识点的固定数据；
2. 在 `TOOLS` 中登记 `id`、标题、`group`、`category`、说明、`nodes` 与 `mount`；
3. 工具页会自动出现在对应功能类目下；
4. 同一工具被多个实验或多个知识点引用时，只登记一次，不要复制实现。

实验与工具共享同一套交互思路，但不要互相复制实现：完整参数、随意试错放在工具里；实验只暴露当前要理解的那一个变量，并在结尾给出相关工具入口。

### 深链接

页面状态会写入 URL hash，可以直接分享或在刷新后恢复：

- `#lesson/<知识点 id>`
- `#experiment/<实验 id>`
- `#tool/<工具 id>`
- `#experiments`
- `#labs`
- `#books`
- `#graph`

## 2D / 3D 关系

2D 与 3D 共用相同节点和边。2D 使用自动生成的平面坐标；3D 在此基础上按必需前置深度增加 Z 坐标。新增节点不需要另写三维位置。
